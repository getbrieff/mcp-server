---
name: technical-analysis
description: >
  Technical indicators and analyst consensus for a stock. Use when the user
  asks about technical analysis, support/resistance levels, RSI, moving
  averages, or analyst ratings for a specific stock.
---

Perform a technical analysis of $ARGUMENTS using Brieff tools:

1. get_technicals - MA50, MA200, RSI-14, short interest, volume, beta
2. get_analyst_consensus - Consensus rating, price targets, recent actions
3. get_company - Current price and basic context

Then present a technical assessment covering:
- Price position relative to MA50 and MA200 (above/below, golden/death cross potential)
- RSI-14 reading and overbought/oversold status
- Volume trends vs average volume
- Short interest level and implications
- Analyst consensus and price target upside/downside
- Recent analyst upgrades or downgrades
- Overall technical outlook
